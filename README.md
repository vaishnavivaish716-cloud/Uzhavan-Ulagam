🌾 Uzhavan Ulagam

Uzhavan Ulagam is a smart farming web application designed to help farmers access useful agricultural information, market prices, job opportunities, and AI-based farming support in one platform.

🚀 Features

- 🌱 Farmer-friendly dashboard
- 🤖 AI-based farming support
- 💰 Mandi / market price information
- 💼 Agricultural job opportunities
- 👨‍🌾 Farmer data management
- 🔐 Login and Admin pages
- 📊 Dashboard and data visualization
- 🗂️ JSON-based database
- 🐍 Python Flask backend

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: JSON
- AI/ML: Python
- Development Tools: VS Code, Git, GitHub
